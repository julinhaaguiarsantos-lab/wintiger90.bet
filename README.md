# Tiger Gold — Slot Demo com artes e animações

Protótipo estático de um slot com:
- artes originais do projeto;
- rolos com parada escalonada;
- brilho e varredura durante o giro;
- efeito de vitória e destaque dos símbolos;
- partículas/moedas na vitória;
- botão GIRAR com feedback visual;
- créditos exclusivamente fictícios.

Não possui depósitos, saques, PIX ou dinheiro real.

Para publicar, envie toda a pasta para um host de site estático como Netlify ou GitHub Pages.
