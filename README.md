# Fortune Arcade — GitHub-ready demo

Uma interface responsiva de **jogos sociais** inspirada em padrões comuns de portais de slots, mas com identidade visual própria.

## Importante

- Esta versão é apenas uma demonstração front-end.
- Usa somente moedas virtuais locais.
- Não possui depósitos, saques, pagamentos, KYC, afiliados ou integração com dinheiro real.
- Não utiliza logos, imagens ou código proprietário de terceiros.

## Rodar localmente

Basta abrir `index.html` no navegador.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `styles.css` e `app.js`.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
4. Salve e aguarde a URL do GitHub Pages.

## Três identidades visuais

A mesma base pode ser aberta com temas diferentes:

- `index.html?brand=fortune` — Fortune Arcade
- `index.html?brand=nova` — Nova Play
- `index.html?brand=velvet` — Velvet Spin

Para produção legalizada, seria necessário substituir o modo demo por serviços autorizados, controles de idade, jogo responsável, conformidade regulatória, auditoria, segurança e políticas de privacidade adequadas.

## Funcionalidade dos botões

Todos os botões principais possuem ação: saldo abre a carteira virtual; Entrar e Criar conta abrem seus formulários; atalhos executam bônus, missões, surpresa, check-in ou roleta; filtros alteram o catálogo; cards iniciam uma rodada demo; e a navegação inferior abre áreas próprias de Início, Promoções, VIP e Perfil.
